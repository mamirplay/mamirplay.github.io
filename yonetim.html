⚙️ İlk kurulum gerekiyor

Yönetim paneli hazır; çalışabilmesi için Supabase bağlantısını bir defaya mahsus kurmalısın.

GitHub Pages tek başına giriş, veritabanı ve APK dosyası yükleme sunucusu sağlamaz. Bu işlemleri güvenli Supabase hesabına bağlayacağız.
  1. Supabase'de ücretsiz proje oluştur.
  2. Hazırlanan supabase-kurulum.sql dosyasını SQL Editor'de çalıştır.
  3. Authentication → Users bölümünden yönetici hesabı oluştur ve kimlik numarasını (User UID) yönetici tablosuna ekle.
  4. Project URL ve publishable/anon key değerlerini mamir-config.js dosyasına yazıp GitHub'a yükle.

Lütfen service_role/secret anahtarlarını ve şifreni kimseyle paylaşma. Özel anahtarlar web sayfasına yazılmaz.

🔐 Yönetici Girişi

Bu ekranda hesap oluşturulmaz. Yönetici hesabını Supabase Authentication üzerinden sen oluşturursun.

⛔ Yetki gerekli

Giriş yapabildin ancak hesabın MAMİR PLAY yöneticisi olarak tanımlanmamış. Supabase'de mamir_admins tablosuna kullanıcı UID'si eklenmeli.
